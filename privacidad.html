Privacidad

Nota Clara está diseñada para guardar tus notas en el almacenamiento local de tu navegador. La aplicación no requiere que crees una cuenta dentro del producto.

Datos de tus notas

Los títulos, contenidos, colores, estados de fijado y papelera permanecen en tu dispositivo mediante almacenamiento local del navegador. No se envían a una base de datos propia de Nota Clara.

Pago

La compra se procesa mediante Stripe. Stripe puede recopilar la información necesaria para completar el pago conforme a sus propias políticas y obligaciones. Nota Clara no almacena datos completos de tarjeta.

Respaldos

Si exportas un respaldo JSON, el archivo contiene el contenido de tus notas sin cifrado adicional. Guárdalo en un lugar seguro.

Almacenamiento técnico

La aplicación usa almacenamiento local para recordar la activación, el tema visual y tus notas. Borrar los datos del sitio puede eliminar esa información.

Cambios

Esta información puede actualizarse si cambia el funcionamiento del producto. Revisa esta página cuando necesites conocer la versión vigente.
